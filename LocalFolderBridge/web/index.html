SECURE MCP TUNNEL
连接与诊断
本机程序不调用模型推理 API。隧道需要独立的 Tunnel ID 与具备运行权限的密钥。

  

    
1 · 安装连接组件
官方来源
使用 OpenAI 官方 tunnel-client，保留下载包中的 cloudflared 等配套文件。安装会联网下载并检查发布资产的 SHA-256。
自动下载失败时可从官方发布页手动下载并完整解压，再选择主程序。不需要关闭杀毒或绕过系统策略。
查看官方发布页 ↗

    
可选 · PDF 文字组件
检查中
文本、DOCX、XLSX、PPTX 不依赖额外安装。读取 PDF 文字需要 pypdf；扫描件 OCR、加密 PDF 不在当前范围。
固定版本与哈希由安装器校验，不从任意镜像执行代码。

  

  
2 · 配置连接
运行密钥至少需要 Tunnels: Read + Use；创建或修改隧道另需管理权限。ChatGPT 和 OpenAI Platform 组织/工作区也必须正确关联，不能仅靠同名账号判断。
官方连接指南 ↗管理 Tunnel ↗

  
3 · 在 ChatGPT 中绑定并验收
在插件/应用的开发者连接中选择 Tunnel，绑定同一个 Tunnel ID。复用现有插件时先核验旧 Tunnel 仍可用；启动服务后点击插件详情的“刷新”。默认应发现 5 个只读工具，启用操作后为 9 个工具。
自检只验证本机 HTTP/MCP，不验证 ChatGPT。真正验收应让 ChatGPT 读取验证文件并原样复述随机字符串，随后核对调用记录。

QUICK REFERENCE
使用说明
完整离线说明在程序目录中的「使用手册.html」。
读取资料
打开程序 → 授权目录 → 启动隧道 → 在 ChatGPT 新对话中启用插件。
使用本机文件插件，先调用 get_status 获取目录列表，再列出“项目资料”目录。阅读报告.md，按 next_start_line 继续直到结束；对未能读取的内容明确说明。
提出文件修改
在本机打开操作总开关及目标目录的操作权限，刷新 ChatGPT 工具。
在指定授权目录中创建总结.md，先提交拟写入内容作为提案，不要声称已经保存。我会在本机审批；之后请调用 get_operation 确认结果。
连接不通时
404：检查旧隧道是否已失效、当前 Tunnel ID 是否匹配、插件是否已刷新。不要直接删除或放宽授权。
401 / 403：检查隧道运行密钥的权限、组织/工作区及本机隧道额外请求头，不要发送凭证到聊天里。
工具存在却无法读取：检查本机是否暂停、目录是否移动、符号链接/敏感文件是否被过滤，以及 PDF 组件是否安装。
没有写入工具：检查双重开关、刷新工具和当前 ChatGPT 账户可用权限；本机程序不能绕过平台限制。
浏览器重开后缺凭证：双击 START.cmd 重新打开管理页，不能仅输入 localhost 地址。
使用边界与退出
程序不把文件服务公开到互联网，不提供远程命令或任意文件下载。路径过滤不能识别普通文档中所有秘密信息。不要授权不允许提供给 ChatGPT 的资料，不要把本程序当成恶意软件隔离沙箱。
正常退出会停止本次隧道和本机服务，取消待审批操作；不会删除授权文件或备份。关闭浏览器标签页不会停止程序。
