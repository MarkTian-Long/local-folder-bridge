## 4. 浏览器检查的真实边界

尝试使用实际 Chromium 打开 loopback 管理 URL 时，环境返回 `ERR_BLOCKED_BY_ADMINISTRATOR`。没有修改或关闭该策略。测试改为：将真实 HTML/CSS/JS 加入 Chromium DOM；显式 sessionStorage 替身提供临时管理凭证；fetch 测试转接由 Python 访问真实 HTTP 服务。MCP 操作提案仍由真实 HTTP JSON-RPC 发给独立 MCP listener。

已验证中文界面、目录授权、目录层级浏览、正文搜索、完整长文续读、文档脚本不执行、操作双开关、提案不先写入、错误确认拒绝、批准后真实写入、远程查询执行结果、程序回收、两次本机恢复确认、暂停阻断读取、恢复、本机协议自检、审计展示、390px 布局与新空授权上下文提示。共 40 项，结果逐项保存在 JSON。

未验证原生浏览器 localhost 导航、真实 sessionStorage 持久化/凭证引导、浏览器端 CSP 强制行为、Windows 文件选择对话框或用户自己的 Edge/Chrome。后端实际 Host/Origin/凭证校验有独立 HTTP 回归，与该浏览器缺口不同。

## 5. 独立进程与 Schema

对 9 个工具的 inputSchema 和 outputSchema 逐项检查；对真实调用返回（包括业务错误）作 JSON Schema 验证。另真实启动 `app.py` 子进程，在 localhost 授权样本、读取、执行自检，正常停止，再重启确认授权保留、操作总开关关闭、管理凭证轮换和运行期凭证文件删除。

这一套验证程序入口与真实 HTTP 服务，不依赖浏览器测试替身；但仍没有启动真实官方 tunnel-client。

## 6. 本轮发现并修复的问题

读取续页增加 expected_sha256，防止拼接两个版本；规范化 Windows 反斜杠相对路径，避免确认文件名不一致；禁止重命名改变扩展名；终态 request_id 不允许重新用于执行；备份前后比对版本与字节哈希并限制容量；用可恢复程序回收区代替可能行为不同的系统回收；异常执行明确记录部分效果可能性；拒绝重复安全 HTTP 头；修复安装器误把官方三个分发变体同时作为完整客户端候选；修复移动端长 SHA 显示导致横向溢出。

另修正 Windows 回归样本的位置：默认系统 TEMP 位于 AppData，本来就被产品目录策略拒绝，不能靠放宽产品安全策略让测试通过。测试脚本改在独立 `LocalFolderBridge-TestRuns` 下创建并清理临时子目录。

## 7. 用户本机复跑

常规回归：完整解压后双击 `RUN_TESTS.cmd`。脚本不触碰已授权业务资料；可能覆盖本包 `reports/local-tests.*` 为你的新结果。没有安装 PDF 时，两个可选 PDF 用例会明确 skipped，而不是伪通过。Windows 无符号链接权限时，对应测试可能明确跳过。

可选开发检查（只在获准的开发环境执行；不影响正常使用）：

```text
python -m pip install -r requirements-dev.txt
python tools/run_tests.py
python tools/verify_delivery.py
python tools/test_browser.py
python -m pytest --cov=bridge --cov-report=term
python tools/verify_package.py
```

浏览器脚本需要已安装 Chromium 或 Playwright 浏览器；可通过 `CHROMIUM_EXECUTABLE` 指定获准的可执行文件。仅在原生导航明确被管理员策略阻止时使用并记录测试适配模式，不关闭浏览器安全策略。依赖下载安装不属于本次 Windows 实机证据。

`verify_package.py` 校验原始交付字节，不是病毒扫描或签名验证；你重跑测试、修改文档或代码后，相关文件哈希变化是预期现象。先区分有意修改与意外篡改，再重建清单，不要为了得到 PASS 擦掉错误。

## 8. 本机上线前的必过检查

在非敏感测试目录依次核验 Windows 双击启动、原生目录选择、中文路径、官方组件下载安装、需要时的 DPAPI 重启、Tunnel doctor/ready、ChatGPT 随机字符串读取、写提案不自动执行、本机批准后变更、恢复原始字节以及正常退出断开服务。只有这些结果在你的机器与账号上实际发生，才能记录“该账号已通过 MCP 读到这台电脑”。

这些检查的操作步骤已写入 `使用手册.html`，不需要再次拼接源码或等待缺失手册。
