# 更新记录

## 1.1.1 — 2026-09-29

- 修复 Windows 默认 GBK 下测试读取中文 UTF-8 文本和 profile 失败，测试工具明确文本编码。
- 修复重复启动时 `--no-browser` 被忽略，并在锁获取失败/端口占用分支关闭文件句柄。
- 统一版本来源为 `bridge/__init__.py`，CLI `--version`、状态、MCP serverInfo 和界面同步显示。
- 分发改为明确文件白名单，拒绝缺失文件、链接/重解析点、硬链接、重复路径和常见凭证形状；归档尺寸受限。
- 可重复 ZIP 字节、SHA-256 sidecar、打包后 CRC/逐文件检查；生成清单只进入 ZIP，不覆写原始导入清单。
- 发布清单拒绝损坏格式、重复条目和白名单不匹配，失败不再意外打印 traceback。
- 新增打包、启动和真实 Windows DPAPI 回归；测试报告写入 `reports/current/`，不覆盖历史交付证据。
- 浏览器测试支持 `--native-only`，新截图与报告一起保存，不覆盖旧手册图片。
- 补开发说明、Windows 复核、发布准备；保留既有 MIT 授权和默认只读边界。
