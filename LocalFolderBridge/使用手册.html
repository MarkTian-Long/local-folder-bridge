本机文件桥 · 操作手册

Local Folder Bridge 1.1.1｜2026-09-29｜Windows 联网启动版

本程序把你明确授权的本机文件夹接到 MCP：ChatGPT 可以列目录、搜索、分段读取文件；启用可选的操作权限后，可以提出文件修改提案，但实际执行必须在本机审批。本程序不是远程桌面，也不会把整台电脑交给模型。

1. 收到的是什么，先打开哪个文件

把整个 LocalFolderBridge.zip 解压到一个稳定、可写的普通目录，例如 D:\Tools\LocalFolderBridge。不要只从压缩包内双击文件，也不要只复制一个启动脚本。

文件 用途
START.cmd 正常启动入口；打开本机浏览器管理界面
使用手册.html 此手册的离线可读版；不启动服务也能打开
README.md 快速开始与交付入口
RUN_TESTS.cmd 在隔离临时目录执行回归测试，不读取授权业务资料
docs/技术说明与安全边界.md 实现、工具清单、格式与权限边界
docs/测试与验收报告.md 已执行测试和未执行环境验收的严格区分
docs/插件配置说明.md 旧插件复用、Tunnel 绑定、工具刷新与错误处理
reports/current/ 本机重跑生成的当前报告，不随分享 ZIP 发送
MANIFEST.sha256 交付文件的 SHA-256 清单

这是一份带界面、启动脚本、完整源代码、测试和说明的程序包，不是签名 EXE 安装器，也不是已内置全部运行环境的离线包。首次运行可自动取得官方 Python；连接隧道和 PDF 组件按需下载。没有要求你逐个拼接源码或编译程序。

2. 首次启动：先把本机读取跑通

准备环境。 目标是 Windows x64 或 ARM64，使用普通用户运行。需要可用的默认浏览器；自动引导和原生文件选择器使用 Windows PowerShell。已安装 Python 3.11 或更新版本时可直接利用；没有时，启动脚本从 Python 官方站取得固定的 3.13.15 嵌入式运行环境并校验固定 SHA-256。企业设备禁止脚本或组件下载时，不要绕过策略，由管理员批准安装或使用获准的 Python 环境。[S4]

双击启动。 双击 START.cmd。等待浏览器管理页打开，保留命令窗口。程序未安装开机启动、Windows 服务或系统托盘组件；关闭浏览器标签页不会停止服务。页面没有自动打开时，再次双击 START.cmd 可重开当前实例的管理页。仅手输本机 URL 会缺少管理凭证。

授权一个测试目录。 在“授权文件夹”点击“选择文件夹”，或粘贴普通项目目录的完整路径，如 D:\MCPData\Test。目录必须已存在。填写别名后点击“授权读取”。不要把示例路径原样粘贴到没有该目录的电脑。

验证读取。 到“浏览与搜索”，选中该目录，点击“浏览”；对一个 TXT 或 Markdown 文件点击“读取”。能显示原文、SHA-256 和必要的下一段按钮，说明本机文件逻辑可用。此时并不意味着 ChatGPT 已经能读到它。

程序最多授权 12 个不重叠目录；不允许整盘、整个用户主目录、程序或状态目录及其上下级。UNC 网络共享、符号链接、目录联接、重解析点、多重硬链接以及敏感名称会被拒绝。OneDrive 等占位或重解析文件应先复制到普通本地测试目录，不要通过放宽过滤来解决。

3. 连接 ChatGPT：三种标识不要混用

这一步需要一个有效的 Tunnel ID、具备运行权限的 隧道运行密钥，以及在目标 ChatGPT 工作区可用的开发者连接权限。Tunnel 的管理权限与 ChatGPT 的开发者模式权限不是同一项。[S1]

名称 放在哪里 不是什么
Tunnel ID，形如 tunnel_ 后接 32 位十六进制字符 本机“连接与诊断”及 ChatGPT 的 Tunnel 连接 不是 App ID、Version ID 或内部网关 URL
隧道运行密钥 仅在本机密码框输入 不是 ChatGPT 登录密码；不要发到聊天中
本机管理凭证 / MCP 凭证 程序自动生成与管理 不需要手工粘贴到网页插件设置

取得或恢复隧道。 在 Platform Tunnel 设置 核验旧隧道是否仍存在、属于正确组织并关联目标工作区。旧隧道有效即可复用；本机程序丢失并不证明云端隧道已经删除。旧隧道无法恢复时创建新的隧道，并在本机和 ChatGPT 中使用同一新 ID。运行或选择隧道需要 Tunnels 的 Read + Use；创建、编辑需要 Read + Manage。无权限时须由对应管理员授权，程序不能代替账号授权。[S1]

安装连接组件。 在本程序“连接与诊断”点击“下载官方隧道客户端”。安装器只选择官方 Windows 对应架构的完整客户端资产，验证发布方 SHA-256；完整包包含相关配套文件，不能只拷走主 EXE。自动下载不可用时，从 OpenAI 官方发布页 下载并完整解压，再点击“选择已有 exe”。选择完整 tunnel-client，不要选名称带 runtime-only 或 runtime-cloudflared 的精简变体，因为本界面还调用 doctor 诊断。[S2]

本机填好配置。 填写客户端路径、Tunnel ID 和运行密钥，点击“保存连接配置”。默认密钥只保存在本次进程内；选择“Windows 当前用户 DPAPI 加密保存”后，程序才会保存当前 Windows 用户可解密的密文。该机制不能保护已经被同一用户恶意程序控制的电脑，也不适用于把密文复制给另一台电脑或另一个 Windows 用户。

诊断、启动、绑定。 点击“运行官方诊断”，通过后点击“启动隧道”。观察健康和就绪状态；进程运行、诊断通过、就绪通过与真正端到端读取是不同状态。在 ChatGPT 开发者连接中选择 Tunnel，选择或粘贴同一个 Tunnel ID。旧插件继续绑定有效旧 Tunnel 时优先刷新工具；新 Tunnel 则更新可编辑的绑定，或创建新连接。不要把 http://127.0.0.1:18766/mcp 当成 ChatGPT 云端可直接访问的公网地址。[S1][S3]

本程序用官方隧道连接，不开公网入站端口；通过 MCP 返回的文件文字仍然进入 ChatGPT，绝不是“文件内容完全不出电脑”。也不要把本程序等同于独立模型服务：它没有调用模型推理 API。[S1]

4. 你的现有网页插件应该怎样处理

原插件名为“本地文件（只读）”。本程序保留 list_files、search_files、read_file 的工具名称，但增加了多目录参数、分页、版本校验及状态工具。因此只看到原来三个旧定义时，不能视为连接已更新。

先启动本机服务与正确的隧道，再在插件详情点击“刷新”。只读模式应发现 5 个工具：get_status、list_files、search_files、read_file、get_operation。本机开启操作总开关后，再次刷新，应为 9 个工具。部分网页缓存需要新建对话后重新启用插件。[S3]

截图中只读工具出现“写入 / 开放环境 / 可修改”类标签，不应靠改为“全部允许”解决。新服务已经声明只读工具 readOnlyHint=true、destructiveHint=false、openWorldHint=false，并提供 outputSchema；写入提案则诚实声明非只读。平台标签的最终展示由 ChatGPT 决定，注解本身不是安全授权。

现有“允许低风险操作”可先保留；它不代替本机目录授权，更不能代替本机审批。启用操作后，可把插件显示名改为“本机文件桥”，但名称修改不是连通性要求。本次交付没有替你修改网页账号配置或注册新 Tunnel。

5. 最低验收：不要把期望答案提前告诉 ChatGPT

在“总览”或“连接与诊断”点击“生成端到端验证文件”。程序会在当前用户目录下的 LocalFolderBridge-Demo 新建随机命名的 TXT 文件，并授权该测试目录。该动作是你在本机主动点击触发的例外，不是模型远程扩权。授权目录已经达到 12 个时，需要先移除一个无关授权。

页面显示两部分：本机期望的随机字符串，以及应发送给 ChatGPT 的提示词。只复制提示词，不复制期望字符串。 在启用本机文件插件的 ChatGPT 新对话中发送它，让模型实际读取文件。

验收必须同时满足：ChatGPT 返回与本机显示一致的随机字符串；本机“调用记录”出现对应 read_file 记录；记录的时间、目标相对路径与这次请求匹配。测试字符串不是秘密，仅用于避免模型猜测或把聊天里已有答案当成读取结果。

程序中的“本机 MCP 自检”只检查 localhost 上的协议握手、工具发现与状态读取；不验证云端账号、隧道、ChatGPT 插件调用或 Windows 浏览器策略。

6. 日常阅读与检索

可以先发给 ChatGPT：

使用本机文件插件，先调用 get_status 获取已授权目录。
在“项目资料”中列出文件。读取需求说明.md，按 next_start_line 继续，
续读带上上一段的 sha256；全部读完后再总结。
对未读到、被过滤、格式不支持或内容截断的部分明确说明，不要猜测。

搜索可以要求：

在已授权的“项目资料”目录中搜索“规则包”，搜索文件名和正文。
有 next_cursor 就继续，直到候选路径处理完；区分匹配结果、解析失败、
不支持的格式和搜索上限。然后读取最相关的文件片段并给出路径及行号。

这是子串搜索，不是语义搜索，也不是自动把整库建立向量索引。一次空结果可能只是一个批次；存在游标时仍须继续。搜索最多收集 5,000 个文件候选，超大目录要缩小子目录。文件在搜索期间可被其他软件修改，因此结果不是所有文件在同一时刻的强一致快照。

格式 返回什么 不能据此声称读到了什么
TXT、Markdown、代码及常见文本 解码后的文字、提取行、SHA-256 执行结果或代码运行正确性
DOCX 正文段落、表格单元格及部分附属文字 完整版式、图片、所有批注或修订语义
XLSX 工作表、单元格地址、文字、公式及已有缓存值；标记隐藏工作表 公式已重新计算、图表已读懂、隐藏内容已自动排除
PPTX 按演示顺序提取的幻灯片文本 动画、图片、图表视觉含义或完整讲稿
PDF 安装 pypdf 后可读文字层与页码标记 扫描件 OCR、图片理解、原版式精准还原或加密 PDF 内容
旧版 DOC/XLS/PPT、图片、ZIP 等 可见时仅列文件信息 已支持其正文解析

单文件上限 25 MiB；提取最多 1,000,000 字符；单次读取最多 400 个提取行、约 40,000 字符。表格/段落的“行”是提取行，不一定对应 Office 的视觉行号。PDF 页码、XLSX 表名与单元格地址等定位比重构后的行号更接近源文档。

PDF 可在“连接与诊断”点击“安装 / 校验 PDF 组件”；安装器固定 pypdf 6.18.1 并核验哈希。本次交付环境的 PDF 回归使用已有 pypdf 5.9.0，没有把 6.18.1 下载安装成功或其完整兼容性写成已验证。本机安装后请用自己的非敏感样本再读一次。[S5]

7. 操作文件：提案、审批、确认结果

先打开两个开关。 在“授权文件夹”打开“允许提交文件操作提案”，并勾选目标目录“此目录允许操作提案”。回到 ChatGPT 插件刷新工具。全局开关在每次正常启动时恢复关闭；目录开关会保留，但单独打开它不能执行操作。

让模型先提出案。 示例：

在“项目资料”目录新建 总结.md，内容是下面的摘要。
先通过 propose_write_file 提交完整文本提案，不要声称已经保存。
我会到本机审批，审批后再调用 get_operation 查询结果。

覆盖原文件时，必须先读取原文件并把该版本 SHA-256 带入提案。重命名或移动只限同一授权目录内的单个文件；目标父目录要已存在、不允许覆盖目标、不能更改扩展名。新建文件夹只创建一级指定子目录；删除只支持单文件进入程序回收区，不支持整目录或远程永久删除。

本机审批。 打开“待审批操作”，核对目录、原目标、移动目标、原因、原始 SHA-256，以及拟写入的完整文本。输入原目标完整文件名（含扩展名），点击“批准并执行”。不满意直接拒绝。提案 15 分钟后过期，队列最多 30 项；关闭操作、暂停或取消目录授权会取消相关待处理提案。

再确认结果。 提案返回 pending 不是保存成功。查询结果必须为 status=completed 且 result.executed=true 才能确认操作完成。failed、interrupted、state_unknown 或 partial_effects_possible 需要在本机核对目标和备份，不要直接重复提案；断电或进程被杀后不会自动重放待执行操作。

可写格式仅 TXT、Markdown、CSV/TSV、JSON、YAML，单次最多 256 KiB UTF-8。写入以 UTF-8 编码，不承诺保留原编码、换行风格、全部权限或扩展属性。不写 Office 二进制、不生成可执行程序，也不执行 shell 命令。对 CSV 公式或会被其他软件当作配置的内容，也应审阅后再批准。

8. 程序回收区与恢复：不是 Windows 回收站

覆盖、移动和回收操作在执行前保存并校验原始字节；新建文件没有旧版本可备份。回收动作在备份成功并再次核对版本后移除原路径的文件，原始字节留在程序自己的回收/备份目录，不调用 Windows 回收站，也没有自动清理任务。

默认位置：%LOCALAPPDATA%\LocalFolderBridge\backups\操作标识\。original.bin 保存原始字节，manifest.json 记录原路径、原哈希和操作信息。总备份额度为 1 GiB，达到后拒绝需要新增备份的操作；需要你在本机安全归档，不会为了腾空间自动删除旧备份。

在有备份的操作卡片点击“从备份恢复为新文件”。输入原授权目录内一个尚不存在的相对路径，再输入恢复目标完整文件名确认。恢复必须保留原扩展名，要求原目录仍授权、操作权限仍开启；不覆盖现有文件，原备份继续保留。原文件名已经空闲时可用原名恢复；仍存在时用新名。

移除目录授权不删除备份。程序内恢复需要原 root_id 的授权仍存在；先移除再重新添加得到的新标识不能自动匹配旧操作，此时须在本机依据 manifest 手工恢复。不要把状态文件夹当作普通缓存清空，否则会失去历史备份。

9. 暂停、退出、升级与卸载

“暂停访问”会阻止受限文件读取/修改，并取消待审批提案；状态与历史结果查询仍可用。暂停后已返回给 ChatGPT 的内容不会被追溯收回。需要停止全部工具服务时，在“使用说明”点击“停止服务并退出”。正常退出会关闭管理服务和本次隧道。

不建议依赖强制关机、结束进程或直接关控制台完成优雅清理。异常结束时，下次启动会把执行中的操作标为中断；请核对文件和备份。睡眠、离线、退出后，ChatGPT 都无法继续读取这台电脑。

升级时先正常退出，再替换同一程序目录内的交付文件；状态默认独立保留在 %LOCALAPPDATA%\LocalFolderBridge。本版保持上轮初版的数据库表结构，但没有对遗失的旧程序做格式迁移承诺。不要向 ChatGPT 上传 state.sqlite3、runtime.json、runtime-key.dpapi、完整备份或真实密钥来求诊断。

卸载时先停止程序、清除已保存密钥，并决定是否撤销网页连接与不再使用的 Tunnel。确认备份已归档后再删除程序目录；状态目录需要你另行决定保留或删除。卸载本程序不应删除已授权业务目录。

10. 故障排查

现象 处理顺序
双击窗口立即退出或下载失败 重新运行查看错误；确认完整解压、目录可写、Python/官方站访问。公司限制由管理员处理，不关闭安全防护
下载文件被系统隔离 查看系统防护历史和具体检测名，交给管理员核验；此包未做你电脑上的杀毒验证，不保证无误报
页面显示缺少管理凭证 重新双击 START.cmd；不要把带认证片段的地址发送给别人
本机端口被占用 关闭旧实例或按下面的高级命令更换两个端口；不能同时多开相同状态目录
原插件 404 核验 Tunnel 是否存在、组织/工作区关联、ID 是否一致、隧道是否运行，最后刷新/重建连接；不是默认“目录权限不够”
401 或 403 分清发生在平台还是 localhost；检查运行密钥的权限、工作区、以及程序生成的 MCP Authorization 请求头；不要全部放开权限
没有 Tunnel 选项或找不到隧道 核验账号/工作区开发者连接能力及 Tunnels Read + Use；本地代码不能绕过平台开关
进程运行但一直未就绪 运行官方 doctor，查看已过滤日志；网络代理、组织权限、服务地址都可能相关
ROOT_CHANGED / NOT_FOUND 核验目录是否移动或被替换，先处理待审批操作，再重新授权；旧提案不能拿新目录自动执行
EXCLUDED / LINK_BLOCKED 敏感路径或链接被拒绝；只把经确认可共享的普通文件复制到测试目录
CONFLICT / FILE_CHANGED 文件已修改；重新读取最新版本再提出新操作，不使用旧 SHA-256 强行覆盖
PDF_COMPONENT_MISSING / 格式不支持 安装 PDF 文字组件，或把源文档另存为支持的文本格式；扫描件不在当前 OCR 范围
BACKUP_QUOTA / DISK_SPACE 先在本机归档备份、释放空间；不要删除唯一副本
操作审批后仍未变更 看 get_operation 实际结果；失败可能有部分副作用，应检查原路径、目标路径和备份

高级启动示例，在程序目录的命令窗口中使用：

START.cmd --admin-port 18865 --mcp-port 18866
START.cmd --no-browser
RUN_TESTS.cmd

如已有获准的 Python，可运行 python app.py。单独 stdio 模式为 python app.py --stdio；它用于其他本机 MCP 宿主，不提供管理界面。不要与同一状态目录的 GUI 实例并行运行。需要独立实例时用不同的 --state-dir 和不同端口，并重新授权自己的测试目录。

11. 手动取得组件，不绕过校验

启动器的 Python 官方 ZIP 地址与 SHA-256 都写在 START.cmd，以架构区分。可以通过获准网络从 Python 3.13.15 官方发布页 取得对应 embeddable package，核验 SHA-256 后完整解压到程序目录的 runtime，使 runtime\python.exe 存在。不要用同名陌生 EXE 替代。[S4]

隧道客户端可从官方最新发布页完整解压到普通目录，再在本机选择主程序，不要修改程序以接受未核验镜像。[S2]

PDF wheel 的固定版本、URL 与哈希见 bridge/downloads.py。通过获准网络取得同一 wheel 并校验后，把其中 pypdf 和对应 .dist-info 目录完整解压到 third_party；重启程序。wheel 是 ZIP 容器，不需要运行里面的任意安装脚本。本手册不附带第三方二进制或字体文件。[S5]
