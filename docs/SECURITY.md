# 安全与隐私

## 授权前先想清楚

只将你有权交给 AI 服务处理的文件放入专用共享目录。**只读表示程序没有写入/删除工具，不表示文件内容不会发到云端，也不表示已获得企业合规许可。**

本服务不主动联网；连接它的客户端或 Tunnel 会把工具结果交给 AI。敏感数据是否允许外传、如何留存，取决于你使用的产品、账号设置和组织政策，不能由本服务代为保证。

## 当前保护

- 必须显式提供一个 `--root`；请求只能传其下的相对路径。
- 同时校验输入路径和解析后的真实路径；列表与搜索跳过链接，直接读取也拒绝符号链接和 Windows 目录联接。
- 拒绝 `..`、绝对路径、带冒号的附加数据流/设备路径、以点/空格结尾的路径段。
- 不提供写入、删除、重命名、执行脚本、任意 URL 获取等工具；三个工具都声明只读。
- 输出不主动显示服务器根目录绝对路径；正文自己包含的个人信息不会被自动脱敏。
- 文件名和正文均提示为不可信数据；参数严格校验，文件读取和扫描有预算。

## 默认排除规则

以下任一相对路径分段匹配（忽略大小写）会被隐藏和拒绝：

- 目录：`.aws`、`.azure`、`.git`、`.gnupg`、`.hg`、`.ssh`、`.svn`、`.tunnel-client`、`.codex`、`.agents`、`.venv`、`venv`、`node_modules`、`.runtime`、`dist`。
- 文件名：`.netrc`、`.npmrc`、`.pypirc`、`credentials.json`、`id_dsa`、`id_ecdsa`、`id_ed25519`、`id_rsa`。
- `.env`、`.env.*`，以及以 `.key/.kdbx/.p12/.pfx/.pem` 结尾的名称。

这既包含敏感路径，也包含为了避免噪声/重复读取而排除的运行产物。目前不可通过工具参数取消这些规则。路径规则只约束授权根目录以下，不会替你判断授权根目录本身是否安全。

## 不能保证的事

这不是操作系统沙箱。Node 进程仍有启动用户的权限；当前代码只是应用层限制。

- 硬链接无法按“真实位置”识别来源；授权目录内的硬链接可能指向其他来源的数据。
- 路径检查和读取之间存在竞态；若其他本机程序恶意替换文件/目录，不能承诺完全阻止。
- 黑名单认名字，不认内容：`notes.txt` 中的口令不会被自动发现；改名后的敏感文件也可能可读。
- 不提供多租户隔离、HTTP 鉴权、文件全文防泄漏、持久审计或资源级沙箱。
- 手写解析器对复杂/恶意文档的覆盖有限；上限降低风险，不代表完成了安全认证。
- “不可信内容”提示和只读标记不是提示注入防火墙，AI 客户端仍需遵守权限和安全策略。

更严格环境应使用低权限账号、只读挂载/隔离容器、固定的资料副本，并限制客户端其他能力；不要把此试用服务当作敌对多用户环境的安全边界。

## 密钥与分享

`scripts/tunnel.ps1` 使用隐藏输入，密钥不放命令参数、不落本项目文件；仅在需要的进程环境中传递。此方法不能防御本机管理员、恶意同用户程序或键盘记录器。

只分享白名单生成的 ZIP。不要发送 `.tunnel-client`、运行日志、个人账号截图、密钥、健康检查地址文件或整个旧项目文件夹。打包器可发现常见 key/Tunnel ID 形状，但**不是完整秘密扫描器**；发送前仍需人工检查。

若密钥误泄露，停止分发，去密钥管理页面撤销并轮换；仅删除聊天文字或 ZIP 不能让已经泄露的密钥失效。反馈漏洞请提供脱敏复现样例，不附真实密钥或业务数据。
